# Skypro.Wallet — Личный финансовый трекер и дашборд аналитики

Современное SPA-приложение на React для учета ежедневных расходов с полноценной системой авторизации, интеграцией с REST API, интерактивным календарем, кастомным дашбордом аналитики и умной фильтрацией за периоды времени.

---

## Основной функционал (Фичи)

- **🔐 Авторизация и регистрация пользователей:**
  - Полноценные окна входа и регистрации с переключением режимов.
  - Интеграция с бэкенд-сервером Skypro API с использованием **Bearer-токенов**.
  - Сохранение активной пользовательской сессии (`userInfo`) и состояния вкладок (`activeTab`) в `localStorage` — аккаунт не сбрасывается после обновления страницы (`F5`).
  - Безопасный выход из аккаунта с подтверждением действия и автоматической очисткой пользовательских данных.
- **🛡️ Умная валидация форм и UX-подсказки:**
  - Проверка имени на отсутствие цифр, строгая проверка почты на домен `@mail.ru` и контроль формата дат (`ДД.ММ.2024` строго для Июля и Августа).
  - Мгновенная визуальная индикация ошибок: красная подсветка полей, динамическая красная звёздочка, следующая за последним введённым символом, всплывающие подсказки под полями и блокировка кнопки отправки.
  - Перехват и обработка сетевых сбоев (ошибка связи при отсутствии интернета, внутренние ошибки сервера `500+` и истечение токена `401`).
- **📝 Учет расходов (REST API):**
  - Загрузка реального списка транзакций пользователя с сервера.
  - Мгновенное добавление новых записей и безопасное удаление с подтверждением и синхронизацией с базой данных.
- **📅 Интерактивный календарь-период:**
  - Кастомная сетка для Июля и Августа 2024 года с корректным календарным смещением дней недели.
  - Автоматическая конвертация форматов дат между клиентским интерфейсом (`ДД.ММ.ГГГГ`), сеткой календаря (`ГГГГ-ММ-ДД`) и сервером (`ММ-ДД-ГГГГ`).
- **📈 Множественный выбор диапазона дат:**
  - Умный выбор периода (от `startDate` до `endDate`). Все промежуточные дни объединяются в единый визуальный блок, а система автоматически суммирует траты за весь выбранный цикл.
- **📊 Динамический категориальный дашборд:**
  - Отображение общей суммы расходов за период и 6 вертикальных капсул категорий (Еда, Транспорт, Жильё, Развлечения, Образование, Другое) с пропорциональной высотой от `4px` до `328px`.
- **🎨 Кастомный UI:**
  - Адаптивная шапка приложения (полная навигация в рабочем пространстве и минималистичный вариант с логотипом на экране входа).
  - Стилизованные тонкие ползунки (`6px`) и прозрачная фокусировка полей ввода без системного желтого автозаполнения.

## Стек технологий

- **Библиотека:** React (Functional Components, Hooks: `useState`, `useEffect`)
- **Сборщик проекта:** Vite
- **Сетевое взаимодействие:** Fetch API (REST, Bearer Token Authentication)
- **Стилизация:** Чистый CSS3 (Flexbox, Grid Layout, Keyframe Animations, WebKit Scrollbar Customization)
- **Иконки и графика:** Инлайновые SVG-векторы
- **Хранилище:** Web Storage API (`localStorage`)

## Инструкция по локальному запуску

Для того чтобы запустить проект на своем компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий или откройте папку проекта:**
   ```bash
   cd SkyproWallet
   ```

2. **Установите все зависимости проекта:**
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки (Vite):**
   ```bash
   npm run dev
   ```

4. Откройте локальный адрес в браузере (по умолчанию: `http://localhost:5173`). Для входа зарегистрируйте новый аккаунт (используйте почту с окончанием `@mail.ru`).
