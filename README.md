# Skypro.Wallet — Личный финансовый трекер и дашборд аналитики

Современное SPA-приложение на React для учета ежедневных расходов с интерактивным календарем, кастомным дашбордом аналитики и умной фильтрацией за периоды времени.

---

## Основной функционал (Фичи)

- **📝 Учет расходов:** Главный экран со списком из 16 предустановленных транзакций. Возможность мгновенного добавления и безопасного удаления записей с локальным резервным копированием в обход сбоев сервера.
- **💾 Архитектура навигации:** Полная фиксация состояния активной вкладки (`activeTab`) в `localStorage`. Приложение не сбрасывает экраны при жесткой перезагрузке или обновлении кода.
- **📅 Интерактивный календарь-период:** Кастомная сетка для Июля и Августа 2024 года. Августовская сетка аппаратно сдвинута под Четверг с помощью неактивных прозрачных заглушек.
- **📈 Множественный выбор диапазона дат:** Умный выбор периода (от `startDate` до `endDate`). Все промежуточные дни закрашиваются в единый визуальный блок, а система нативно суммирует траты за весь выбранный цикл дней.
- **📊 Динамический категориальный дашборд:** Отображение общей суммы за период крупным шрифтом и 6 фиксированных вертикальных овальных капсул (Еда, Транспорт, Жильё, Развлечения, Образование, Другое). Высота столбиков физически меняется от `4px` до `328px` в зависимости от доли категории.
- **🎨 Кастомный WebKit UI:** Полностью стилизованные тонкие ползунки (`6px`), идеально закругленные со всех сторон с помощью `background-clip` и встроенных радиусов. Компактная геометрия элементов.

---

## Стек технологий

- **Библиотека:** React (Functional Components, Hooks: `useState`, `useEffect`)
- **Сборщик проекта:** Vite
- **Стилизация:** Чистый CSS3 (Flexbox, Grid Layout, WebKit Scrollbar Customization)
- **Иконки и графика:** Инлайновые SVG-векторы
- **Хранилище:** Web Storage API (`localStorage`)

## Инструкция по локальному запуску

Для того чтобы запустить проект на своем компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий или откройте папку проекта:**
   ```bash
   cd SkyproWallet
   ```

2. **Установите все зависимости проекта:**
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки (Vite):**
   ```bash
   npm run dev
   ```

4. Откройте локальный адрес в браузере (по умолчанию: `http://localhost:5173`).
