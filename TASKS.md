## 📝 Детальное описание тикетов Канбан-доски

### 🟢 ВЫПОЛНЕНО (DONE)

#### [SW-01] Архитектурная фиксация состояния активной вкладки
* **Описание:** Настройка сохранения текущей вкладки навигации при перезагрузке страницы или обновлении кода сборщиком Vite.
* **Реализация:** Реализована ленивая инициализация состояния `activeTab` из памяти браузера через `localStorage` и хук `useEffect`.
* **Чек-лист:**
  - [x] Проверка сохранённого ключа `walletActiveTab` при старте приложения.
  - [x] Автоматическая запись состояния при переключении между экранами.
  - [x] Предотвращение сброса на первую вкладку при Хот-Релоаде.

#### [SW-02] Изолированная сетка августа и неактивные заглушки
* **Описание:** Сдвиг 1-го августа строго под Четверг без дублирования текстовой шапки дней недели.
* **Реализация:** Использован массив `augustEmptySpaces` из 3 элементов для генерации прозрачных неактивных кнопок-заглушек `.empty-space`.
* **Чек-лист:**
  - [x] Полное удаление дублирующей строки дней недели под словом "Август".
  - [x] Реализация 3 невидимых ячеек для понедельника, вторника и среды.
  - [x] Блокировка кликов и наведения (`pointer-events: none`) на заглушках, чтобы не путать пользователя.

#### [SW-03] Оптимизация и укорачивание кастомных ползунков
* **Описание:** Кастомизация системных скроллбаров, приведение ползунков календаря и таблицы к единому компактному стилю.
* **Реализация:** Ползунок календаря укорочен нативным методом через спайсер контента в `750px`. Ползунок таблицы трат укорочен через `background-clip: padding-box` и прозрачные рамки `border-width: 80px 4px`.
* **Чек-лист:**
  - [x] Ширина дорожек зафиксирована на изящных `6px` / `12px`.
  - [x] Обеспечена 100% плавная и свободная прокрутка без рывков.
  - [x] Встроенный `border-radius: 30px` идеально закруглил верхний и нижний радиус обоих ползунков.

#### [SW-04] Динамическая диаграмма из 6 вертикальных капсул
* **Описание:** Переход от простых горизонтальных строк аналитики к полноценному категориальному дашборду.
* **Реализация:** Настроен расчёт доли каждой из 6 категорий от общей дневной суммы. Удалены серые треки, теперь цветные столбики `.v-bar-standalone` физически растут от пола вверх в диапазоне от `4px` до `328px`.
* **Чек-лист:**
  - [x] Суммирование расходов по 6 фиксированным категориям (Еда, Транспорт, Жильё, Развлечения, Образование, Другое).
  - [x] Округление всех четырёх углов столбиков для создания формы овальных капсул.
  - [x] Плавная анимация изменения высоты через `transition: height 0.3s cubic-bezier`.

#### [SW-05] Минималистичный текстовый блок и геометрия панели
* **Описание:** Оптимизация размеров интерфейса и стилизация заголовков для улучшения визуального восприятия.
* **Реализация:** Ширина календаря зажата на аккуратных `260px` для сохранения ровных кругов дат. Верхний блок аналитики переверстали: сумма выведена крупным жирным шрифтом, а под ней через класс `.highlight-date` выведена яркая дата.
* **Чек-лист:**
  - [x] Календарные кнопки защищены от растягивания во всю ширь на больших мониторах.
  - [x] Межстрочный интервал суммы сжат до `line-height: 0.9` для уменьшения зазора до даты.
  - [x] Элементы графика подтянуты выше к тексту за счёт сброса верхнего `padding`.

#### [SW-06] Выбор промежутка дат с автоматическим закрашиванием
* **Описание:** Добавление возможности анализировать траты за диапазон дней (например, за неделю или выходные).
* **Реализация:** Стейт переведён на хранение границ периода — `startDate` и `endDate`. Разработан алгоритм, который автоматически закрашивает синим цветом все дни календаря, попавшие внутрь диапазона, и суммирует расходы за этот период.
* **Чек-лист:**
  - [x] Хронологическая калькуляция трат за весь выбранный промежуток дней.
  - [x] Реализована автоматическая текстовая подпись диапазона (например, "Расходы за 19 – 25 июля 2024").
  - [x] Углы крайних дней диапазона закругляются в аккуратную общую линию.
